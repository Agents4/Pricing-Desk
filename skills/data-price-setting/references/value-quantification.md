# Quantifying customer value

Start from the customer's outcome, not the data. Write the value chain in one line: "With this data, [buyer] does [action], which changes [metric] by [amount], worth [money] a year."

## Method

1. Pick the decision the data changes (which fares to publish, which suppliers to prefer, where to add capacity, which markets to enter).
2. Name the metric it moves: cost avoided (leakage, search cost, analyst time), revenue enabled (conversion, yield, share), or risk reduced.
3. Get the baseline and the change from the buyer: ask for a recent example, not a general opinion.
4. Convert to yearly money for one buyer at the usage you expect.
5. Haircut for the share of the benefit that comes from the data and not from the buyer's own work (often half or less).
6. Record the source: estimate (our guess), interview (the buyer gave the numbers), pilot (measured), contract data (from a signed deal).

## Interview questions that work

- What decision does this data help you make, and how do you make it today?
- Last time, what did the wrong call cost you?
- What would you do with it that you cannot do now? What is that worth over a year?
- What do you use instead, and what does it cost in money and in time?
- Who signs off on the spend, and what return do they need?

## Cautions

- Stated value is optimistic. Cross-check with a second buyer in the same segment.
- Do not count value that depends on rights you do not have (for example, display to third parties when the register says Unknown).
- Value scales with coverage and freshness. State both.
- Keep each buyer's figures confidential; use ranges in shared outputs.
